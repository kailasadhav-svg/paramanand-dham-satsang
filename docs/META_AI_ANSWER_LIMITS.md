## २) अजपा AI उत्तरासाठी आमचा नियम (अ‍ॅप)

| नियम | मूल्य | का |
|------|-------|-----|
| किमान शब्द | **२००** | साहित्याचा पूर्ण अर्थ |
| कमाल शब्द | **४५०** | मराठी ~२–३.५k अक्षरे; WhatsApp text आत |
| WhatsApp text कमाल | **४००० अक्षरे** | + footer ≤ ४०९६ |
| Template param / संक्षेप | **१०२४ अक्षरे** | `{{2}}` / notify |
| Interactive preview | **१०२४ अक्षरे** | बटण मेसेज |

**प्रवाह**
1. AI पूर्ण उत्तर तयार करते (२००–४५० शब्द).  
2. DB / अ‍ॅप मध्ये तेच ठेवते.  
3. WhatsApp पाठवताना `≤४०००` अक्षरे (footer आधी).  
4. Template वापरायचे झाले तर फक्त **संक्षेप ≤१०२४**; पूर्ण उत्तर अ‍ॅप लिंकने.

## ५) टेम्प्लेट Reject नंतर व्यावहारिक सल्ला

1. **२४ तास session** मध्ये पूर्ण AI उत्तर `sendText` ने पाठवा (≤४०९६).  
2. बाहेर session असेल तर: छोटा template (“उत्तर तयार — अ‍ॅप पाहा”) + अ‍ॅप लिंक; पूर्ण मजकूर template variable मध्ये **टेकू नका**.  
3. Login OTP फक्त **Authentication** category.
